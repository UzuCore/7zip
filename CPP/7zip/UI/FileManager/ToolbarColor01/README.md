# Color toolbar set 01

Artwork: Assets/UI/toolbar-color01-transparent.png, derived with the built-in
image generation editor from row 01 COLOR of toolbar-icon-sets-8-v1.png.
The transparent source and exact image-generation prompt are preserved in Assets/UI.

The checked-in ICO files are generated by Installer/build_toolbar_icons.py
(Pillow required only to regenerate assets). Each ICO contains 24, 36, 48 and
64 pixel, 32-bit alpha images. The build uses the checked-in icons directly.
The metadata file records each atlas cell and measured artwork bounds.

Windows desktop toolbars use 24 pixel images in small mode and square 36 pixel
images in large mode. Original command IDs and button labels are retained.
The classic bitmap resources remain available as a fallback.

Local validation: MSVC x64 build; seven native icon resources loaded at both
24px and 36px as 32-bit color; seven runtime toolbar buttons; small/large icons
on Light/Dark backgrounds; repeated toolbar rebuilds had bounded GDI/User counts.
Review screenshots: color01-small-light.png, color01-small-dark.png,
color01-large-light.png and color01-large-dark.png in the local preview review folder.
